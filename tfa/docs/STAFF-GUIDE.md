# Thinking Fish Assist: staff guide

For Thinking Fish engineers. Customers get the customer guide at https://thinking.fish/assist-guide.

## 1. What is where

| Piece | Where | Notes |
|---|---|---|
| The app | https://thinking.fish/assist (files are GitHub release assets) | Same app for staff and customers |
| ID + relay server | `assist.thinkingfish.com` (AWS Lightsail `tf-assist`, London) | Open-source RustDesk server 1.1.16; its key is built into every copy of the app |
| Staff console | https://assist.thinkingfish.com/_admin/ | Users, shared address books, device list, login/connection/file-transfer logs |
| Source | https://github.com/thinking-fish/thinking-fish-assist | Public (AGPL-3.0); never put a password or key in it |
| Credentials | vault `services/thinking-fish-assist.md` | Console break-glass admin, keystores, server key |

The app needs no configuration: our server and its key are fixed in the build and cannot be changed in
Settings, so a customer cannot point it at someone else's server by mistake.

## 2. Getting set up (once)

1. Install Thinking Fish Assist on your own PC or Mac (see the customer guide; on Windows click **Install**).
2. Ask Andrew to add you to the Entra enterprise app **Thinking Fish Assist staff sign-in**
   (Entra admin centre > Enterprise apps > that app > Users and groups > Add). Only assigned people can sign in.
3. In the app, open the **Address book** tab and click **Login**, then **Continue with Microsoft**.
   Sign in with your thinking.fish account; your normal Microsoft MFA applies. The first sign-in creates
   your Assist account automatically.
4. New accounts join the **Staff** group automatically, which shares the **Customers** address book
   (read/write) with you. Admins: console > System > **UserManage** > (user) > edit; tick **Admin** only for people who
   manage the console.

## 3. Helping a customer (attended)

1. Send them to **thinking.fish/assist** (or read it out). Windows users will see the SmartScreen
   "Windows protected your PC" box: tell them **More info > Run anyway**.
2. They read you the number under **Your ID**.
3. Type the ID into **Control Remote Desktop** and press **Connect**.
4. The customer clicks **Accept** in the window that pops up. You do not need their one-time password,
   and you should not ask for it; the click is the consent.
5. Toolbar at the top of the session: file transfer, chat, voice call, record, screenshots, Ctrl+Alt+Del,
   restart remote device (reconnects afterwards), privacy mode / block input (Windows), multi-monitor.
6. Before you disconnect, tell the customer what you did. Offer to add them to the address book (section 5).

The session shows **Direct** or **Relayed** in the toolbar tooltip. Both are fine; relayed sessions go
through our London server and are still end-to-end encrypted.

## 4. Unattended access (managed computers)

Only with the customer's written agreement (support contract or email). Record it in the ticket.

### Windows
1. Run the app as the customer (or yourself, remotely) and click **Install**, or use the silent install
   below. Installing creates the Windows service `ThinkingFishAssist`, so it starts before anyone logs in
   and works on the login screen.
2. Set a permanent password: in the app, **Settings > Security > Password > Set permanent password**,
   or from an elevated prompt:
   `"C:\Program Files\ThinkingFishAssist\ThinkingFishAssist.exe" --password "<long random password>"`
   Use a unique 20+ character password per computer, generated by the password manager.
3. Get the ID: `"C:\Program Files\ThinkingFishAssist\ThinkingFishAssist.exe" --get-id`
4. Add it to the shared address book (section 5) with the password saved.
5. Optional hardening: **Settings > Security**: enable **2FA** (TOTP) for unattended access if the
   customer wants it, and turn off features they do not want (file transfer, audio, etc.).

### Mac
1. Install from the DMG into Applications and open it.
2. Grant **Screen & System Audio Recording** and **Accessibility** in System Settings > Privacy & Security.
   This needs someone at the Mac (or an MDM profile for Accessibility; Apple does not let MDM pre-approve
   screen recording for a standard user, only let the user approve it).
3. In the app, click **Install** / start the service when asked (admin password), then set a permanent
   password in **Settings > Security**.
4. Add it to the shared address book.
Note: until the Mac app is signed with our Developer ID (pending), macOS may drop these permissions after
an update; re-grant them if a Mac shows a black screen.

### Android
Not suitable for unattended support: Android requires the user to start screen sharing each time.

## 5. Address book and device list

* **Device list** (console > System > **PeerManage**): every installed copy that has reached our server, with ID, host name,
  OS and last-seen time. Use it to find a customer's ID when they cannot read it out.
* **Shared address book "Customers"**: owned by the console admin and shared read/write with the **Staff**
  group (console > System > **AddressBookNameManage**, share rules). Entries can be added from PeerManage with **AddToAddressBook**. Use one entry per computer: ID, alias
  ("Customer - machine"), a tag per customer, and for unattended computers the saved password. More books
  can be added the same way (e.g. one per large customer).
* In the app, the **Address book** tab shows the books shared with you once you are signed in.

## 6. Silent install for managed machines (RMM / Intune / GPO)

MSI (preferred for managed estates):

```
msiexec /i Thinking-Fish-Assist-windows-x64.msi /qn /l*v C:\Windows\Temp\tfassist.log
msiexec /i Thinking-Fish-Assist-windows-x64.msi /qn CREATEDESKTOPSHORTCUTS=0 CREATESTARTMENUSHORTCUTS=1 INSTALLPRINTER=0
```

Properties: `INSTALLFOLDER` (default `C:\Program Files\ThinkingFishAssist`), `CREATESTARTMENUSHORTCUTS`,
`CREATEDESKTOPSHORTCUTS` (1/0), `INSTALLPRINTER` (1/0, the remote-printing driver).

EXE (same file customers use):

```
Thinking-Fish-Assist-windows-x64.exe --silent-install
```

After either, from an elevated PowerShell:

```powershell
$app = "C:\Program Files\ThinkingFishAssist\ThinkingFishAssist.exe"
& $app --password "<unique password>"      # permanent password for unattended access
& $app --get-id                            # prints the ID; record it in the address book
& $app --option <key> <value>              # any other setting, e.g. allow-auto-record-incoming Y
```

Uninstall: Settings > Apps, or `msiexec /x Thinking-Fish-Assist-windows-x64.msi /qn`, or
`"C:\Program Files\ThinkingFishAssist\ThinkingFishAssist.exe" --uninstall`.

macOS has no silent install that can grant screen recording; deploy the DMG with your MDM and have the
user approve the permissions once.

## 7. Logs and audit

Console (admins), under System: **LoginLog** (staff sign-ins), **AuditConnLog** (who connected to which ID,
when, from which IP, and when it closed), **AuditFileLog** (file transfers). Session recordings, if switched on, are saved on the computer that
recorded them (Settings > Recording), not on the server.

## 8. If something is wrong

| Symptom | Check |
|---|---|
| App says "Not ready" / no ID | Can the machine reach `assist.thinkingfish.com` TCP 21115-21117 and UDP 21116? Firewalls on customer networks sometimes block them. |
| "Key mismatch" | The app is not our build (e.g. stock RustDesk). Download it again from thinking.fish/assist. |
| Black screen on a Mac | Screen Recording permission missing or revoked; re-grant it and restart the app. |
| Cannot sign in with Microsoft | The user is not assigned to the Entra app (section 2). |
| Server alarm on Telegram | See `tfa/docs/SERVER.md`. |
